# HyperData Signals — индикатор для TigerTrade (пилот)

Показывает сигналы скринера прямо на графике TigerTrade:

- **Маркер** на каждой отправленной карточке: ▲ касается цены снизу (покупатели), ▼ сверху (продавцы),
  ◆ на цене (сторона не определена). У сильных маркер крупнее и подписан `!!`, рядом tier и вердикт.
  Старые сигналы бледнеют к концу окна истории.
- **Импульс:** линия от начала 30-секундного импульса до цены сигнала и две полоски объёма за 15с
  (зелёная — покупки, красная — продажи, длина пропорциональна).
- **Результат** по свечам графика: пунктир до цены через 5 минут (или до текущей, если 5 минут ещё
  не прошло), бейдж «+0.40% за 5м · в пользу …% · против …%» и полупрозрачная полоса диапазона.
  Зелёный — сигнал оправдался, красный — нет, серый — у сигнала нет стороны.
- **Зона:** прямоугольник от момента появления зоны; толщина растёт с размером в $.
  Последняя зона тянется до правого края с подписью «$11k · съедят за ~16с», прошлые — бледные.
- **Панель:** в свёрнутом виде заголовок и вердикт, полная карточка при наведении курсора.
- **Карточка у курсора:** наведите курсор на свечу с маркером, и рядом появится полный текст сигнала.
- **Алерт:** в настройках индикатора («Алерт → Новый сигнал») можно включить звук или всплывающее
  окно TigerTrade на каждую новую карточку по открытому инструменту.

Индикатор только читает данные: не торгует и ничего не меняет в скринере. Он раз в 2 секунды запрашивает
`GET /v1/scalper/chart-marks?code=<Symbol.Code>&exchange=<Symbol.Exchange>&minutes=N` у локального скринера.
`BTCUSDT` на `BINANCE-FUT` сопоставляется с `BINANCE:BTC`, затем с `BTC` (Hyperliquid).

## Сборка и установка

Нужен .NET 10 SDK. TigerTrade сам индикаторы не компилирует, он загружает готовые DLL.

```
dotnet build integrations/tigertrade/HyperDataSignals -c Release
copy integrations\tigertrade\HyperDataSignals\bin\Release\net10.0-windows\HyperDataSignals.dll %USERPROFILE%\Documents\TigerTrade\Indicators\
```

Если TigerTrade установлен не в `C:\Program Files (x86)\TigerTrade`, добавьте `-p:TigerTradeDir=<путь>`.
Перезапустите TigerTrade, затем «Менеджер индикаторов» → **HyperData Signals**.

## Настройки

| Настройка | По умолчанию | |
|---|---|---|
| Адрес скринера | `http://127.0.0.1:8421` | |
| История, минут | 120 | какие карточки показывать на графике |
| Размер текста | 11 | |
| Панель (полная при наведении) | вкл | |
| Результат сигнала (до 5 минут) | вкл | |
| Импульс и объёмы 15с | вкл | |
| Алерт → Новый сигнал | выкл | звук или окно TigerTrade |
| Эмодзи в тексте | выкл | шрифт графика может не отображать эмодзи |

## Ограничения пилота

- Внутренний API индикаторов TigerTrade описан только примерами. После обновления терминала
  индикатор может понадобиться пересобрать.
- Время меток переводится из UTC в часы биржи через `TimeHelper.GetCurrTime`, как в таймере свечи Tiger.
- Результат считается от цены карточки по свечам графика. Свеча сигнала пропускается, потому что
  большая часть её диапазона была до карточки. На старших таймфреймах 5 минут — это часть одной свечи.
- Карточка у курсора показывается по свече под курсором; если на ней несколько сигналов, показан последний.
- На графике видны только отправленные карточки. Кандидаты из тихого списка не показываются.
