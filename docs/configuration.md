# Настройки рабочего контура

Корневой `.env` задаёт локальный профиль. `.env.example` — шаблон для новых
установок; изменение шаблона не меняет ваш `.env`. Секреты не входят в Git.

## Почему строки закомментированы

`#` в начале строки означает, что настройка не загружается. Это не означает,
что функция проекта выключена: код может использовать значение по умолчанию,
настройку из SQLite или значение, которое передаёт launcher.

| Группа | Значение для текущего запуска |
|---|---|
| `AI_PROVIDER=openrouter`, `OPENROUTER_*` | Основной контекстный AI; локальная выбранная модель и ключ сохранены |
| `GEMINI_*` | Альтернативный провайдер; при OpenRouter не используется |
| `GEMINI_API_KEY_1`…`GEMINI_API_KEY_10` | Текущий runtime их не читает, ротации этих ключей нет |
| `LLM_*` | Отдельная paper-стратегия `llm_agent`, не AI скринера |
| `PULSE_API_URL` | Launcher задаёт `http://127.0.0.1:8431`; явная строка помогает ручному запуску |
| `PULSE_SHADOW` | По умолчанию `1`: историческая оценка качества; отключение не выключает публикацию attention |
| Пустые `*_DATA_DIR`, `HYPERDATA_HISTORY_DIR` | Используются штатные пользовательские каталоги |
| `HYPERDATA_UNIVERSE_LIMIT` | Standalone HyperData; не ограничивает полный обзор unified до 60 монет |
| `SCALPER_AI_MODE`, `SCALPER_AI_EARLY` | Совместимость со старым фильтром; не меняют текущий relative attention и выбор free/strong |
| `SCALPER_AI_EXPERIMENTS` | Парные вызовы в unified всегда принудительно отключены |
| `HYPERDATA_DIGEST_SECONDS` | Старый digest; при Telegram UX не используется |
| Пустой analytics chat / operator IDs | Не создают нового назначения аналитики или дополнительных операторов |
| `HYPERDATA_UNSAFE_PUBLIC_API` | Опциональное открытие доступа; локальному профилю не требуется |

Несколько ключей Gemini в комментариях увеличивают число закомментированных
строк, но не добавляют доступных возможностей к выбранному OpenRouter.
Раскомментирование всех строк не улучшит качество отбора.

## Приоритет настроек

1. Унаследованные переменные процесса имеют приоритет над `.env`
   (`load_dotenv(..., override=False)`). Если значение неожиданное, проверьте
   окружение, из которого запущен проект.
2. Корневой `.env` читается при запуске. Launcher передаёт служебные параметры
   единого режима и адрес Pulse дочерним процессам.
3. Политика AI, сохранённая из панели в `scalper_settings`, имеет приоритет над
   начальными `SCALPER_AI_*` из `.env`. Для изменения существующей политики
   используйте панель; изменение `.env` не перезапишет её молча.
4. В едином контуре платный лимит ограничен сверху 40/час, эксперименты выключены.
   Более низкий лимит теперь сохраняется при перезапуске. Настроенный cooldown
   используется free/strong/meta-маршрутами, а статус показывает его значение.

Верхний лимит запросов не является денежным бюджетом: стоимость зависит
от выбранной модели и размера входа/ответа. Локальные 40/час и 300 секунд
в этой донастройке не увеличивались. Free: отдельно 12/час и 40/сутки;
нулевая цена проверяется по каталогу, платного fallback нет.

## Профиль для полноты данных и качества отбора

С 07.11.2026 [Binance USDT-M участвует в том же adaptive attention](binance-adaptive.md).
Обзор больше не ограничен каталогом HL; индивидуальные инструменты не прописываются
в `.env`. Общая настройка HTTP/HTTPS-прокси для бирж: `HYPERDATA_EXCHANGE_PROXY`.
Пусто — прямой доступ; после заполнения нужен перезапуск. Адрес не следует
публиковать в чате или отчёте.

| Параметр | Значение | Причина |
|---|---:|---|
| Обзор | Каталоги Binance USDT-M и HL | Отбор по относительной активности без Top-20 по объёму |
| `SCALPER_ATTENTION_SLOTS` | 20 | Бюджет подробных обзорных снимков |
| `PULSE_ATTENTION_DETAIL_SLOTS` | 6 | Бюджет исполнений и L2; из них до двух защищённых контекстов |
| `PULSE_ATTENTION_HOLD_SECONDS` | 600 | Достаточно времени на прогрев 5m и оценку изменения контекста |
| `PULSE_SHADOW` | 1 | Сохранять историческую диагностику пригодных минут |
| `HYPERDATA_HISTORY_MAX_BYTES` | 5 GiB | Сохранён существующий бюджет; 48 часов, с защитой неполных архивов |
| `SCALPER_CONTEXT_AUTO` | true | Только содержательные изменения, без расширения квот |

До исправления `PULSE_ATTENTION_HOLD_SECONDS` игнорировался, всегда применялось
600 секунд. Теперь значение используется. Для совместимости допускается
60..3600 секунд, но защищённому контексту требуется минимум 330 секунд:
300 даст фактические 330. План показывает `requested_hold_seconds` и
`hold_seconds` отдельно. Локальный `.env` установлен в 600, что сохраняет
прежнюю фактическую длительность.

Удержание относится к защите до двух focus-эпизодов от вытеснения, а не к
максимальному возрасту каждого активного инструмента. Остальные слоты адаптивны.
Потеря свежести освобождает даже защищённый эпизод. Lease плана — отдельные
60 секунд: при прекращении обновлений подробные подписки освобождаются.
Изменение длительности применяется к новым резервированиям контекста;
уже сохранённые сроки эпизодов не переписываются задним числом.

Пустые пути в Windows означают native-данные в `%LOCALAPPDATA%/hyperdata`,
журнал скринера в `%LOCALAPPDATA%/hyperdata-screener/scalper.sqlite`, историю
в `%LOCALAPPDATA%/hyperdata-screener/market-history`. Смена пути не переносит
историю и может создать видимость пустого проекта. Пути и существующие данные
при этой донастройке сохранены.

## Как раскрывать возможности проверяемо

Сохраняйте непрерывный сбор: частые перезапуски сбрасывают свечной контекст,
которому нужны целевая минута и 14 предыдущих полных минут одного epoch.
До этого `warming_up` ожидаем; отсутствие обновлений спокойного инструмента
остаётся явным, а не заменяется нулевой активностью. Увеличение слотов до
восьми без измерения потерь и нагрузки не является подтверждённым улучшением.

Проверяйте `/overview` (распределение ready/warming_up/missing), `/attention`
(desired/confirmed и живость коллекторов) и `/health` (исторические разрывы,
ресурсы). Увеличивайте охват по результатам сравнения выбранных эпизодов с
контролями в [оценке прикладной пользы](practical-utility-2026-11-07.md).
Накопление достаточной истории и проверка на отложенном периоде важнее
увеличения числа моделей или сообщений.

Новые версии кода загружаются при перезапуске; текущие фактические 20/6/600,
OpenRouter, free-маршрут и лимиты уже соответствуют локальному профилю.
Полный перезапуск ради одних поясняющих изменений `.env` не нужен.

Проверка 07.11.2026: фактический профиль API — 20/6/600, платный лимит 40/час,
cooldown 300 секунд. Бесплатный маршрут подтверждён каталогом. В последнем
часовом срезе у free было 4 успешных ответа из 12 попыток (6 invalid_response,
2 incomplete); у meta — 5 успешных. Это диагностика формата/валидации, не
оценка торговой пользы. Частоту запросов по такому результату не увеличивали.
В широком обзоре 11 инструментов достигли ready, 121 был warming_up, 39 missing;
короткий срез не заменяет длительную оценку покрытия. Полный набор проверок после
донастройки: 855 passed, 4 skipped; Ruff для изменённых Python-файлов прошёл.
